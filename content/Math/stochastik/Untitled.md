- **Damit 2 Ereignisse unabhängig von einander sind muss $\large P(A \cap B ) = P(A) * P(B)$ sein**


- **Erwartungswert $\large E(X) = n*p$** 
- **Standardabweichung $\large \sigma(X) = \sqrt{ n*p*(1-p) }$** 

- **Signifikanzniveau die maximale Irrtumswahrscheinlichkeit** 
- Binomialkoeffizient: $\large \dbinom{n}{k} = \dfrac{n!}{k!(n-k)!}$ 
- Binomialverteilung: $\large P(X=k) = \dbinom{n}{k} * p^k * (1-p)^{n-k}$ 


- Beispiel: $\large A = \{1,2,3,4\}$  $\large B = \{1,2,3,4\}$ 
- Schnittmenge: $\large P(A \cap B ) = \{3,4\}$ 
- Vereinigungsmenge: $\large P(A \cup B ) = P(A) + P(B) - P(A \cap B )$
